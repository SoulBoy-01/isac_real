## 3　七天排期

### D0　今天（无设备，8 小时）

**目标：把设备时间全部留给跑数据。**

| 顺序 | 任务 | 判据 | 若完不成 |
|---|---|---|---|
| 1 | 建 `paper1-framing` 分支，开 `data/` 目录 | 可提交 | — |
| 2 | **写四模式 + CRC16 + 五个埋点** | 编译通过、埋点可打印 | **最高优先，其余可延** |
| 3 | 离线模拟器：失步率 vs p 三条曲线 | 能出图 | 可延到 D6 |
| 4 | 预写判定脚本（读日志算 SAR / 失步 / 恢复时间） | 能吃一份样例日志 | 可延 |

**埋点清单**

```
blocks_total / framing_drop / seq_gap / misalign_events / bytes_delivered
```

`misalign_events`：连续 3 块内找不到 `00 00 00 01`，记一次。

### D1　上机第一天：基线 + 自检 + 找 p 的落点

**这是全周最关键的一天——p 找不到落点，后面全是死水。**

| 时段 | 任务 | 判据 |
|---|---|---|
| 09:00–10:30 | **基线核对**（不可跳过）：旧配置跑 5 min，记时延/吞吐/CFO/丢块 | 时延偏差<15%、吞吐<20%，否则先查天线 |
| 10:30–11:30 | **libfec 自检**：注入 0–16 个错误 | 全部还原且纠正数=注入数；17 个返回不可纠 |
| 13:00–16:00 | **tx_gain 扫点找 p**（见下表） | **p 落在 10⁻⁴–10⁻³ 的那一档** |
| 16:00–17:30 | 四模式各跑 1 min，确认都能出画 | 四种模式均可运行 |

**tx_gain 扫点表**

| tx_gain | 相对衰减 | 实测 p | 可用性 |
|---|---|---|---|
| 31.5 | 0 dB | | |
| 25 | ~6 dB | | |
| 20 | ~11 dB | | |
| 15 | ~16 dB | | |
| 10 | ~21 dB | | |
| 0 | ~31.5 dB | | |
| 0 + 30dB 固定 | ~61 dB | | 可能直接挂 |

**若全档位 p 都在 10⁻⁵ 以下**（M1 组不会失步）：
→ 立刻改设计，主结论转为"M0 vs M1 的确定性差异 + 人为翻转 bit 的因果"，放弃"自然误码导致失步"的叙述。

### D2　核心实验：消融（RS 关闭）

**一次编译跑完四模式，避免反复重编译。**

| 时段 | 任务 | 条件 |
|---|---|---|
| 09:00–12:00 | RS 关闭，跑 M0/M1/M2/M3 | 每模式 5 min × 3 次，**顺序随机** |
| 13:00–14:30 | 数据初检 | **M0 是否 ≈100% 失败**？若不是，M0 做得不干净，立即排查 |
| 14:30–17:30 | 补跑异常组 | — |

**四模式**

```
M0 无锚点   : [payload]                         接收端无法定界
M1 裸前缀   : [2B len][payload]
M2 前缀+CRC : [2B len][2B CRC16][payload]       CRC 失败丢该块
M3 定长分片 : [2B seq][1022B]                   无需 len
```

**核心判据**：M0 失败率 ≈100% 且**不随 p 变化** → 证明"约定缺失是确定性的"。

---

### D3　核心实验：消融（RS 打开）+ 因果验证

**下午那一组是整篇论文的一句话结论。**

| 时段 | 任务 | 判据 |
|---|---|---|
| 09:00–12:00 | RS 打开，重跑 M0–M3 | 与 D2 形成 4×2 矩阵 |
| **13:00–14:30** | **M3(RS关) vs M1(RS开)** | **无显著差异 → 分帧完整性可替代纠错** |
| 14:30–16:00 | 人为翻转 len 的 1/2/3 bit | 变长组 1 bit 即失步；M3 无显著变化 |
| 16:00–17:30 | 补跑 + 备份 | — |

**若设备今天出任何问题，宁可牺牲其余，也要保住 13:00 那组。**

## 5　判定标准（跑之前写死）

| 指标 | 定义 | 阈值 |
|---|---|---|
| SAR | 可用帧/总帧 ×100%，可用 = **VMAF ≥80**（或 PSNR ≥30 dB） | — |
| $N_{\text{mis}}$ | 连续 3 块无起始码，记一次 | — |
| $T_{\text{rec}}$ | 失步到重新出画的中位数 | — |
| $D$ | 时延线性回归斜率 [ms/min] | $\|D\|<1$ 视为无累积 |
| p | LDPC 输出处字节错误率，PRBS 逐字节比对 | ≥10⁶ 字节/点，给 95% 区间 |
| 基线核对 | 时延偏差 / 吞吐偏差 | <15% / <20% |

**两条最核心**

- **M0 失败率 ≈100%，不随 p 变** → 约定缺失是确定性的
- **M3(RS关) ≈ M1(RS开)** → 分帧可替代纠错

## 6　每条实验线失败时的退路

| 若…… | 说明 | 论文改法 |
|---|---|---|
| M1 在 D1 工作点从不失步 | p 太低 | 主结论改为 M0/M1 确定性差异 + 翻转 bit；"自然失步"降为讨论 |
| M0 不是 100% 失败 | M0 没做干净（可能仍带着某个定界手段） | 排查 M0 定义，重做；或承认"上游有隐性定界" |
| M3 配不上 GStreamer | 定长分片不可用 | 只保留 M2，结论缩为"CRC 可兜底" |
| γ 拟合不出双因子 | 数据不足以分离 | 只报四个 γ 值 + 相对比值，不建模型 |
| 时延漂移率算不出来 | 采样点太少 | 报区间，不报漂移率 |

## 8　三条纪律

1. **一次只改一个变量。** 改分帧就别同时改码率。
2. **每个条件跑完立刻存数据。** 设备可能明天就没了。
3. **判据写在跑之前。** 看到结果再定标准 = 数据作废。
