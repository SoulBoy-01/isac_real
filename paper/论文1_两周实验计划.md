# 论文 1 两周实验与写作计划

> 目标：14 天后拿到**可直接写成论文结果章**的数据、图、表。
> 论文 1 暂定题：**《强内码 ISAC 链路上实时视频的保护层定位：分帧完整性、容器放大与缓冲策略》**
> 承诺的结论：**视频的失效边界不在纠错强度，而在分帧元数据的完整性；容器与解码器决定同一误码流的放大倍数。**

## 二、逐日计划

### D1 ｜ B：把 γ 从“四个数”做成“一个模型”

| 项 | 内容 |
|---|---|
| 做什么 | 从现有 pcap/日志中，为四种传输栈分别提取：① 每次失步后的**重新锁定字节数**；② 失步持续时长分布；③ 每损失 1 字节对应的数据丢失量 |
| 方法 | 把 γ 分解为 **γ = γ_header × γ_state**：γ_header 由头部暴露算（28/4≈7，已有）；γ_state 由实测重锁定时间反推 |
| 产出 | **表 4-1**：四栈的 γ、主导机制、实测重锁定字符数、拟合 γ_state |
| 判定 | 若拟合出的 γ_state 能把 VLC 的 500× 与 GStreamer 的 4× 同时解释到同一数量级，模型成立 |

### D2 ｜ B：出图 + 写 4.2 节初稿

| 项 | 内容 |
|---|---|
| 产出 | **图 4-1**：γ 分解图（堆叠柱：γ_header 与 γ_state 各占多少） |
| 产出 | 4.2 节初稿 800 字：模型 → 实测 → 偏差归因 |
| 判定 | 能用一句话说清“为什么 VLC 比 GStreamer 高两个数量级” |

### D3 ｜ 代码：两种分帧模式

| 项 | 内容 |
|---|---|
| 做什么 | 在 `OFDMModulator/Demodulator` 增加两个模式：**① 定长分片**（每包固定 1024 B，不足填充，接收端按固定长切）；**② 前缀 + CRC**（2 B 长度 + 2 B 校验） |
| 产出 | 可从 YAML 切换的三个模式（变长 / 定长 / 前缀+CRC），编译通过 |
| 风险 | 若定长模式改动大，降级为“只做前缀+CRC”——它同样能证伪“前缀是单点故障” |

### D4 ｜ 设备回来第一天：基线核对（**不可跳过**）

| 项 | 内容 |
|---|---|
| 做什么 | 用**旧配置**跑 5 分钟：时延、吞吐、CFO、RS 失败计数 |
| 为什么 | 搬运可能动了天线/校准；不核对，后面所有“改进”都可能只是状态差异 |
| 产出 | **表 4-0**：基线核对记录（与 8 月历史数据对比） |
| 判定 | 时延与历史差 < 15%，吞吐差 < 20%，否则先排查再继续 |

### D5 ｜ A：分帧四组对照（核心实验）

| 项 | 内容 |
|---|---|
| 条件 | ① 变长前缀 + 无外码 ② 定长分片 + 无外码 ③ 前缀+CRC + 无外码 ④ 变长前缀 + 外码（基线） |
| 每条件 | 5 分钟 × 3 次重复，同一位置、同一码率 |
| 产出 | **表 4-2**：四组的可用帧率、失步次数、恢复时间中位数 |
| 预期 | ②③ ≈ ④ >> ① —— 若成立，机制坐实 |

### D6 ｜ A：机制验证（把“相关”变成“因果”）

| 项 | 内容 |
|---|---|
| 做什么 | 在发送端**人为翻转长度字段的 1/2/3 个比特**，观察接收端行为 |
| 产出 | **图 4-2b**：失步概率 vs 长度字段错误比特数（三组曲线） |
| 判定 | 变长组在 1 比特即失步；定长/CRC 组应无显著变化 |

### D7 ｜ C：SNR 维度

| 项 | 内容 |
|---|---|
| 条件 | 可调衰减 0 / 5 / 10 / 15 / 20 dB × {无外码, 有外码} × 2 分钟 |
| 产出 | **图 4-3**：可用帧率 vs 衰减（两条曲线） |
| 判定 | 两条曲线的交叉点 = **外码开始起作用的 SNR**，这就是研究内容 2 的“激活点”雏形 |

### D8 ｜ 时延重测

| 项 | 内容 |
|---|---|
| 做什么 | 至少 20 个采样点（现在只有 8 个）；能上硬件时间戳最好，不能则用更高帧率拍摄 |
| 产出 | **图 4-4**：时延分布（箱线图或带区间的时序），替换原来的 8 点折线 |
| 判定 | 报告“中位数 + 区间”，不再出现 ±0.5 ms |

## 四、风险与降级方案

| 风险 | 概率 | 降级方案 |
|---|---|---|
| 设备一直不回来 | 中 | 先做 B（D1–2）+ 写作（D11–14 的 4.2/4.4），A/C 顺延；论文先按“测量 + 机制假设”投，但**只能冲 C** |
| 定长模式改动太大 | 中 | 只做“前缀 + CRC”一组对照，仍能证伪单点故障 |
| 衰减器不可用 | 低 | 用距离（1/3/5/8 m）替代衰减，代价是可复现性差 |
| 时间戳做不出来 | 中 | 采样点加到 20+，报告区间而非标准差 |
| 重复次数不够 | 高 | 至少 3 次；每次换一个起始相位，避免同一次上电 |

## 五、三条纪律

1. **每个实验结束立刻存原始数据**，文件名带日期与配置，别等“回头整理”。
2. **每次只改一个变量**。改分帧就别同时改码率。
3. **判定标准写在实验之前**，不要看到结果再定标准——那是自欺。
