## 使用说明

**每个 Q&A 文件的结构**

```
## 我的回答（原文）
（作者自己的回答，不改）

## 逐条评判
✅ 对的 / ⚠️ 部分对 / ❌ 错的，附理由

## 更正与补充
把错的地方讲透，并给出依据

## 这一轮新增的概念
术语表，便于复习
```

**为什么保留错误答案**

错误答案本身是有价值的：
1. 复习时能看到"我当时是这么想的"，避免重复踩坑
2. 答辩时被问到类似问题，能想起自己曾经错在哪
