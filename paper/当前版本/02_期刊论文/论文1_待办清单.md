## P1　决定能否投 EI

### ☐ P1-1　A 组：分帧四组对照（1 天）★核心实验

| 组 | 分帧方式 | 外码 |
|---|---|---|
| ① | 变长前缀 | 无 |
| ② | 前缀 + CRC | 无 |
| ③ | 定长分片 | 无 |
| ④ | 变长前缀 | 有（基线） |

- **控制变量**：四组必须同码率、同分辨率、同 GOP、同位置、同天线朝向
- **重复**：5 min × 3 次，**顺序随机**（防热漂移偏向某组）
- **记录**：SAR、`misalign_events`、恢复时间中位数、`bytes_delivered`
- **判据**：若 ②③ ≈ ④ ≫ ①，则"分帧元数据是约束"成立

### ☐ P1-2　机制验证：人为翻转长度字段（0.5 天）★把相关变因果

- 发送端翻转长度字段的 1/2/3 个比特，每档 60 s，三组各做一遍
- 记录每组每档的 `misalign_events` 与 SAR
- **判据**：变长组 1 比特即失步；定长组与 CRC 组无显著变化

### ☐ P1-3　γ 双因子分解所需的重锁定测量（1 天）★今天就能做

- 从 pcap/日志提取：①每次失步后的**重新锁定字节数**；②失步**持续时长分布**
- 拟合 $\gamma_{\text{state}}$，使 $\gamma=\gamma_{\text{header}}\times\gamma_{\text{state}}$ 同时解释 4× 与 500×
- **判据**：同一拟合式能把两个相差两个数量级的结果解释到同一量级

### ☐ P1-4　VMAF 逐帧评分（2 天）★所有 SAR 的前提

- 录接收端画面 → 与源视频逐帧对齐（Pearson 相关）→ 算 VMAF
- 无法解码的帧用"上一可解码帧"填充（Iqbal 2019 做法），保证帧数与参考一致
- 产出：每组 SAR、可见损伤事件计数、冻结时长分布

### ☐ P1-5　C 组：冗余度 × SNR 扫描（1 周）

| 维度 | 取值 |
|---|---|
| 外码 t | **0 / 1 / 2 / 8 / 16**（nroots 0/2/4/16/32） |
| 衰减 | **0 / 5 / 10 / 15 / 20 dB** |
| 每点 | 2 min，记录 SAR 与 $N_{\text{mis}}$ |

- **前置**：可调衰减器量程覆盖 30–40 dB（待确认）
- **判据**：能画出多 SNR 下的"SAR vs t"曲线族，看出悬崖位置
- **LIbfec 好处**：`nroots` 是运行期参数，扫 5 档只需改一个数

## P2　提升质量（非必须）

### ☐ P2-1　时延重测（1 天）

- **优先硬件时间戳**（编码前打单调时钟、解码后取出）；做不到用高帧率拍摄
- **≥20 个采样点**，最好 5 min 连续轨迹
- 报告：**中位数 + p95 + p99 + 漂移率 D**，不再报标准差

### ☐ P2-2　16QAM 分阶段计时（0.5 天）

- 接收端分别打点：软解映射耗时、LDPC 译码耗时
- 判据：给出 QPSK 与 16QAM 两档的两个数字，能判定瓶颈归属

### ☐ P2-3　CP=64 失锁机制核验（0.5 天）

- ①重编译并核对依赖帧长的常数（CP 128→64 使帧长 2.304→2.176 ms）
- ②画 LMMSE 估计的功率时延谱
- 判据：附加时延 < 1.28 μs → 是帧长失配；> 1.28 μs → 是多径
