## 2. 专业硬伤

### B1 — BER 超出样本量能力
样本：10⁶ 码字 × 504 bit = 5.04×10⁸ bit。零误码的 95% 置信上界 ≈ 3/N ≈ **6×10⁻⁹**。
报告称"低于 5×10⁻¹⁰"，**比数据支撑的上界低一个多数量级**。
建议表述："在 5.04×10⁸ bit 窗口内未观测到稳态残留误码，95% 置信上界 6×10⁻⁹"。

### B2 — 8.4% 无推导
`223/191 − 1 = 16.8%`。计入 2 字节长度前缀后如何得到 8.4%，报告未给公式。
需明确"吞吐率"定义域（PHY 净荷 / UDP 净荷 / 端到端视频）。

### B3 — GPSDO 与相噪的机理错误
§8 称选用"内置 GPSDO 高稳定度时钟源…以规避双站异步钟差"，以此作为微动感知对策。
GPSDO 驯服的是**长期频漂**，对 0.1–100 Hz 偏频处的**近载波相噪**无效。
单站优势的真实来源是**收发共本振、相噪共模相消**。

### B4 — 单站自干扰缺失
TX 30 dB / RX 30 dB / 50 MHz 带宽，直耦泄漏与人体回波可差 60–90 dB；
3 m 距离分辨率下**无法用距离门分离**。报告仅提"高通 IIR 滤除静态杂波"，
未做链路预算、未提收发隔离与 ADC 动态范围。

### B5 — 呼吸谐波与心率频段重叠
f_r≈0.2–0.5 Hz → 2f_r≈0.4–1.0、3f_r≈0.6–1.5 Hz，**与 0.8–2.0 Hz 心率带完全重叠**。
线性带通无法分离。报告停留在"结合谐波抑制或高阶谱估计"，**无具体算法**。

### B6 — 3000 kbps 上限无推导
按配置核算：符号时长 (1024+128)/50e6 = 23.04 µs；帧 100 符号 = 2.304 ms；
约 900 数据子载波 × QPSK × LDPC 1/2 → 约 **39 Mbps**。
报告"3000 kbps 上限"低一个数量级，未给任何推导或实测曲线。

### B7 — 时延测量精度与手段不符
分解表七项全落在 0.1 ms（200.0 / 18.0 / 10.0 / 9.0 / 5.0 / 5.0 / 2.3），合计 249.3 却写 250.0，
百分比合计 99.7。而测量手段是"光学帧计数，单帧分辨率约 33 ms"——**33 ms 分辨率无法支撑 0.1 ms 分解**。
